# Wallpapers

<p align="center">
  <img src="assets/banner.png" alt="Wallpapers Banner" width="100%" style="border-radius: 8px;">
</p>

Colección personal de fondos de pantalla organizada por temática, pensada para tenerla sincronizada (vía OneDrive/Git) y compartida entre varios equipos.

- 🖥️ La carpeta [`Main`](Main/) es la que apunta el slideshow de fondos de pantalla de Windows. Añade o quita imágenes ahí para cambiar lo que se muestra en el escritorio.
- 🗂️ El resto de carpetas organiza toda la colección por temática, para poder navegar y elegir wallpapers fácilmente.
- 📁 Cada carpeta temática incluye su propio `README.md` con la vista previa de todos sus wallpapers.
- ⭐ Este proyecto está inspirado en [Joao2Pereira1/Wallpapers](https://github.com/Joao2Pereira1/Wallpapers).
